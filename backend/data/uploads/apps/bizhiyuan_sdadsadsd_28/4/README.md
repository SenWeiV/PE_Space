# 终端平替 - 脚本运行器

## 功能介绍
为无 Python 环境的用户提供的一个通用脚本运行终端平替。支持上传 Python 脚本、上传所需数据文件，提供可视化的终端输出窗口，并支持下载运行后生成的结果文件。

## 环境依赖
已预装常用数据处理依赖（pandas, requests, openpyxl, numpy, tqdm）。如果您的脚本需要其他特殊依赖，请确保它们包含在部署环境的 `requirements.txt` 中。

## 数据存储
- 工作区（隔离环境）：`/app/data/workspace/`
- 所有上传的脚本、数据以及运行生成的产物都会暂时存放在此工作区，运行结束后供用户下载。

## 使用说明
1. **上传脚本**：在页面左侧上传您的 `.py` 格式的主脚本（如 `main.py`）。
2. **上传数据**：如果有依赖的 CSV/Excel 等数据文件，请在对应的上传框批量上传。它们会被存放在与脚本同级的目录中。
3. **运行脚本**：点击「▶️ 运行脚本」按钮，脚本将在后台执行。
4. **查看终端**：在右侧的「🖥️ 终端窗口」中，您可以实时查看到脚本运行中的 `print` 输出和报错信息（即标准输出和标准错误）。
5. **下载结果**：脚本执行完成后，您可以在下方看到工作区的所有文件，并选择打包下载所有结果，或单独下载指定的文件。

## 注意事项
- 文件名里一定不要有空格，否则会报错！
- 工作区在每次点击「运行」时会被清空重置，以避免上一次运行的数据污染。
